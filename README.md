# CYBER BREACH

## 概要
CYBER BREACH は、HTML・CSS・JavaScriptを使用して開発する、SF風のハッキングパズルゲームです。

数字や記号のパターンを解読しながら、ミッションのクリアを目指します。

## 使用技術
- HTML
- CSS
- JavaScript

## 主な機能（実装予定）
- 数字や記号のパターンパズル
- 暗号解読ミッション
- 制限時間とスコア
- ミッションのクリア・失敗判定
- ハイスコアの保存

## 起動方法
`index.html` をブラウザで開いてプレイします。
